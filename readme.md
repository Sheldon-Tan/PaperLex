# 📖 Academic Word Recorder (智能学术生词本与 AI 阅读助手)

专为 **计算机与人工智能（AI）领域学术文献精读** 打造的轻量级桌面悬浮查词与生词资产沉淀工具。

> 💡 **特别说明：无需 API Key 即可直接使用！**  
> 本工具内置了完备的高速词典与学术形态分析引擎，**完全免费、零成本开箱即用**。日常文献阅读中的单词查询、音标展示、分词/复数原形还原、学术短语拆解均由本地与免费引擎高速完成；DeepSeek API 仅作为**可选的高级扩展插件**（用于深度解析极小众的学术黑话与公式机理）。

---

## ✨ 核心特性

### 🆓 1. 免费基础引擎（零门槛、秒级响应、效果同样出色）
* **⚡ F8 极速悬浮划词**：在任意 PDF 阅读器（Adobe Acrobat、Edge 等）、浏览器或编辑器中划选文字，按下 `F8` 秒级唤出置顶小窗口。
* **🌱 语法变形与原词智能还原（Lemmatization）**：自动识别分词（-ing）、过去式、过去分词、名词复数等形态，智能弹出 `[🔍 查原词]` 按钮，支持自由选择存原词还是变形词。
* **🧩 复合词与学术短语智能拆分**：遇到连字符自造词（如 `tag-retrieved`），自动执行多词素拆解并展示分词详解。
* **💡 拼写纠错推荐**：划选不全或手民误打时，自动推荐最相近的候选词卡片，点击即可秒级切换。
* **📊 Excel 本地私有化归档**：查词完毕敲击 `Enter` 键即可将词条写入本地 `words.xlsx`，首列自动加粗排版。

---

### 🤖 2. 深度 AI 扩展（可选配置）
* **顶会语境专精推演**：针对常规词典未收录的前沿复合词、专有模型缩写（如 `IG-Kinetics`），可一键调用 DeepSeek 生成全称背景、数学机理与顶会应用场景。
* **双向表达联想**：输入中文（如“鲁棒性”），自动匹配 5 组学术论文中最地道的英文专业表达。
* **动态计时与熔断**：DeepSeek 查词配备实时跳秒计时器与 60 秒超时安全熔断机制。

## ⌨️ 快捷键与操作指南

| 按键 / 交互 | 作用域 | 功能描述 |
| :--- | :--- | :--- |
| **`F8`** | 全局系统 | 捕获当前划选文本并唤出置顶悬浮窗；未划选时直接唤出并聚焦输入框 |
| **`Enter`** | 悬浮窗口 | 一键将当前查词结果保存至 `words.xlsx` |
| **`Esc`** | 悬浮窗口 | 快速隐藏悬浮窗口，无缝返回文献阅读 |
| **`🔍 查原词`** | 悬浮窗口 | 检测到分词/过去式/复数时，点击一键切换查询单词原型 |
| **`🤖 DeepSeek`** | 悬浮窗口 | *(可选)* 触发 AI 领域专精深度解析（启动 60s 实时计时） |
