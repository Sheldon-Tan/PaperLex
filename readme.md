# Academic Word Recorder

专为计算机与人工智能学术论文精读设计的轻量级悬浮查词与生词记录工具。

核心查词、词形还原、动词形态及同根派生拓展**基于本地规则与免费接口运行**，零配置开箱即用；DeepSeek API 仅作为深度学术术语解析与反义词补全的可选扩展。

---

## 核心功能

### 1. 结构化联想记忆
* **同源词与派生网络**：自动提取词根派生词汇，按词性（名词、形容词、副词等）分类展示关联词条与释义。
* **近义词与学术替换**：聚合常见同义词组，辅助论文阅读理解与学术写作润色。
* **精准反义词推演**：针对具备语义对立性的核心词汇，自动提供反向表达。
* **动词形态与英/美拼写**：识别动词词性时，自动排版展示过去式、过去分词、现在分词及第三人称单数，并标注双写 l、-ise/-ize 等英美拼写差异。

### 2. 高效查词与形态学分析
* **F8 全局划词**：在 PDF 阅读器、浏览器或编辑器中划选文本，按 F8 唤出置顶悬浮窗；未划选时直接唤起并聚焦输入框。
* **形态学原形逆推**：自动识别分词（-ing）、时态（-ed）及拉丁/希腊不规则复数（如 media -> medium、criteria -> criterion），提供一键跳转原词。
* **学术复合词拆解**：针对连字符自造复合词，自动执行多词素拆解并生成分词详解。
* **拼写纠错推荐**：划选残缺或拼写有误时，自动推荐相近候选词卡片。

### 3. 深度学术推演（可选 API 扩展）
* **顶会语境解析**：针对前沿模型缩写或学术生词，可一键调用 DeepSeek 接口生成算法原理、数学机理与顶会应用场景。
* **汉译英学术表达**：输入中文术语，生成 5 组适用于顶会论文写作的地道英文表达。
* **请求监控与熔断**：API 调用配备实时秒级计数器与 60 秒超时自动熔断保护机制。

### 4. 本地数据归档
* **一键导出 Excel**：按 Enter 键即时将词条、音标、词性、释义与记录时间追加至本地 words.xlsx，首列自动排版加粗。

## 快捷键与操作

| 按键 / 交互 | 作用域 | 功能说明 |
| :--- | :--- | :--- |
| **`F8`** | 全局系统 | 捕获选中文本并唤出悬浮窗；无选中时直接打开并聚焦输入框 |
| **`Enter`** | 悬浮窗口 | 保存当前词条至 words.xlsx |
| **`Esc`** | 悬浮窗口 | 隐藏悬浮窗口并释放焦点 |
| **`查词`** | 悬浮窗口 | 检索输入框中的自定义单词或短语 |
| **`查原词`** | 悬浮窗口 | 命中词形变化时，点击切换查询基础原型词 |
| **`DeepSeek`** | 悬浮窗口 | 触发大模型学术深度解析（最长等待 60 秒） |

## 安装与使用

### 1. 安装依赖

环境要求：Python 3.8+

```bash
pip install requests keyboard pyperclip openpyxl
```

### 2. 运行脚本
```bash
python word_recorder3.5.py
```

### 3. 配置说明（可选）

首次运行会自动生成 config.json。如需使用大模型深度解析，在文件中填入 API Key：
```bash
JSON
{
    "enabled": true,
    "api_key": "sk-your-deepseek-key-here",
    "base_url": "[https://api.deepseek.com](https://api.deepseek.com)",
    "model": "deepseek-v4-flash"
}
```
若不配置 API Key，基础查词、动词时态、同源词、近义词与 Excel 保存功能均可完全正常使用。
