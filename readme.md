# 📖 Academic Word Recorder (智能学术生词本与 AI 阅读助手)

专为 **计算机与人工智能（AI）领域学术文献精读** 打造的轻量级桌面悬浮查词与生词资产沉淀工具。

通过全局热键、分流查询引擎、形态学原词还原与 DeepSeek 深度学术解析，将“读文献、解黑话、记生词”的链路压缩至一次按键。

---

## ✨ 核心特性

* **⚡ F8 极速悬浮划词**：在任意 PDF 阅读器（Adobe Acrobat、Edge 等）、浏览器或编辑器中划选文字，按下 `F8` 秒级唤出置顶小窗口。
* **🧠 DeepSeek AI 顶会专精解析**：
  * 内置针对 NeurIPS / ICML / CVPR / ICLR / ACL 等顶级会议的专家提示词。
  * 专解学术黑话、专有缩写（如 `IG-Kinetics`）与算法机理，支持多达 10,000 Tokens 完整输出。
  * 配备 **秒级动态计时器** 与 **60 秒超时熔断保护**。
* **🌱 语法变形与原词推荐（Lemmatization）**：自动识别分词（-ing）、过去式、过去分词、名词复数等形态，支持一键切换查询词根原型，或直接保存当前变形词。
* **💡 智能拼写纠错**：遇到拼写错误或划选不全时，自动提供相近候选词卡片，点击即可秒级重查。
* **🔄 中英学术发散联想**：输入中文关键词（如“鲁棒性”），自动推荐 5 组学术论文中最地道的英文表达。
* **📊 本地私有化存储**：查词结果一键（`Enter`）落盘至 `words.xlsx`，首列自动加粗、释义自动换行，配备线程写入锁。
* **🪶 极致轻量**：基于 Python 原生 Tkinter 开发，无需安装 PyQt 等大型 GUI 框架，内存占用极低。

---

## ⌨️ 快捷键与操作指南

| 按键 / 交互 | 作用域 | 功能描述 |
| :--- | :--- | :--- |
| **`F8`** | 全局系统 | 捕获当前划选文本并自动唤出置顶悬浮窗；未划选时唤出并聚焦输入框 |
| **`Enter`** | 悬浮窗口 | 一键将当前查词结果保存至 `words.xlsx` |
| **`Esc`** | 悬浮窗口 | 瞬时隐藏悬浮窗口，无缝返回文献阅读 |
| **`🤖 DeepSeek`** | 悬浮窗口 | 触发 AI 领域专精深度解析（启动 60s 实时计时） |
| **`🔍 查原词`** | 悬浮窗口 | 点击切换至检测到的动词/名词原型 |
