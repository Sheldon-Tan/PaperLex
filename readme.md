# 📖 智能生词与短语记录本 (Smart Vocabulary Recorder)

基于 Python 与有道词典底层 API 的轻量级生词记录工具。支持单词、短语及整句翻译，具备**智能拼写纠错**、**英美双音标提取**与 **Excel 自动排版**功能，专为文献阅读、论文撰写与英语备考场景设计。

---

### ✨ 核心特性

* **多场景智能解析**：
  * **单词模式**：自动提取英/美双音标、词性划分（`n.`, `v.`, `adj.` 等）及完整中英文释义。
  * **短语/搭配模式**：识别 2~5 词常用搭配，聚合词典与网络释义。
  * **句子/段落模式**：自动触发整句机翻与语法解析。
  * **复合词与修饰过滤**：支持带音标直接粘贴（如 `word /wɜːd/`）、带括号说明及斜杠并列词（如 `Phonemes / Visemes`）。
* **智能拼写纠错（Typo Recommendation）**：
  * 自动拦截误拼单词与生僻缩写，提供 Top-5 纠错候选词。
  * 支持输入数字序号一键切换目标词，或输入 `N` 忽略。
* **Excel 自动排版与样式美化**：
  * 首次运行自动生成标准 `words.xlsx`。
  * 单词列自动**加粗排版**，长释义启用**自动换行**与垂直居中，列宽自动适配。
* **网络防卡死优化**：
  * 强制直连机制，避免系统代理或 VPN 导致网络请求挂起。
  * 支持已有词条查重提示。

### 🛠️ 环境准备

依赖 Python 3.8+ 及以下第三方库：

```bash
pip install requests openpyxl
```

---

### 🚀 快速使用

1. **运行脚本**：
   ```bash
   python words_recorder.py
   ```
2. **交互说明**：
   * **输入词条**：直接输入英文单词、短语或整句后按回车。
   * **确认保存**：
     * 按 `[Enter]`：确认将当前解析词条保存至 `words.xlsx`。
     * 输入 `[N]` / `[n]`：放弃本次记录，不写入表格。
   * **拼写纠错**：
     * 若提示疑似拼错，输入对应数字序号（如 `1`、`2`）即可一键替换为推荐单词。
   * **退出程序**：输入 `q` 或按 `Ctrl + C`。

### ⚙️ 常见问题

* **报错 `PermissionError`**：说明 `words.xlsx` 正在被 Excel 或 WPS 独占打开，关闭表格后再次确认即可正常写入。
* **网络请求超时**：脚本已预设 5 秒超时保护与代理穿透，如遇网络波动重试即可。
