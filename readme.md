# 📖 Smart Vocab Recorder (智能生词与表达记录本)                                                                                   
>> >>                                                                                                                                                 
>> >> 一个轻量、高效的 Python 命令行生词管理工具。支持**交互式即时查词**与**旧表格批量导入补全**，自动抓取英/美双音标、多词性及完整中文释义，并实时美 化排版写入本地 Excel 文档。                                                                                                                           
>> >>                                                                                                                                                 
>> >> ---                                                                                                                                             
>> >>                                                                                                                                                 
>> >> ## 🌟 核心特性                                                                                                                                  
>> >>                                                                                                                                                                                                                                                                                                       
>> >> - 🔍 **全场景智能语义分流**：                                                                                                                                                                                                                                                                         
>> >>   - **单词**：自动提取英/美标准双音标、全部词性（n./v./adj./adv. 等）及分行完整释义。                                                                                                                                                                                                                 
>> >>   - **短语搭配**：深度解析网络释义与常用短语搭配，自动标记类型为 `[短语]`。                                                                                                                                                                                                                           
>> >>   - **长句 / 句子**：自动调用在线翻译引擎生成准确中文译文，自动标记类型为 `[句子]`。                                                                                                                                                                                                                  
>> >> - 📊 **Excel 自动化专业排版**：                                                                                                                                                                                                                                                                       
>> >>   - 第一列单词/内容**自动加粗（Bold）**。                                                                                                                                                                                                                                                             
>> >>   - 释义单元格**自动开启文本换行与垂直居中**。                                                                                                                                                                                                                                                        
>> >>   - 预设自适应列宽与浅灰表头底色，生成的表格清爽整洁。                                                                                                                                                                                                                                                
>> >> - ⚡ **批量导入与断点续传 (`import_words.py`)**：                                                                                                                                                                                                                                                      
>> >>   - 仅需提供第一列包含英文的历史 Excel 文件，一键批量补齐音标与释义。                                                                                                                                                                                                                                 
>> >>   - **智能去重**：自动对比目标表格，已收录词汇自动跳过。                                                                                                                                                                                                                                              
>> >>   - **逐条落盘**：查完一条立即保存一条，中途随时按 `Ctrl + C` 退出也不会丢失数据。                                                                                                                                                                                                                    
>> >> - 🛡️ **高鲁棒性与网络防卡顿**：                                                                                                                                                                                                                                                                      
>> >>   - 模拟浏览器请求头（`User-Agent`），防止被反爬拦截。                                                                                                                                                                                                                                                
>> >>   - 内置强制网络直连策略，彻底避免开启 VPN / 代理时请求挂起卡死。                                                                                                                                                                                                                                     
>> >>   - 智能清洗括号备注（如 `Kinda (kind of)`）、自带音标及斜杠复合词（如 `Phonemes / Visemes`）。
